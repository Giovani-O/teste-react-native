# School Manager

Aplicativo mobile para gerenciamento escolar.

## Versões das principais dependências

- **React Native:** 0.81.5
- **Expo:** 54.0.x
- **Gluestack UI:** 3.0.x
- **Nativewind:** 4.2.x
- **Zustand:** 5.0.x
- **Vitest:** 3.1.x

## Pré-requisitos

- Node.js (versão 18+)
- npm ou yarn
- Expo CLI

## Instalação

1. Clone o repositório
2. Instale as dependências:

```bash
npm install
```

## Executando o projeto

Para iniciar o projeto, execute:

```bash
npm run start
```

Este comando irá gerar um QR code no console. Escaneie o QR code com o aplicativo **Expo Go** no seu dispositivo móvel para rodar o aplicativo.

### Opções adicionais

- **Android:** `npm run android`
- **iOS:** `npm run ios`
- **Web:** `npm run web`
